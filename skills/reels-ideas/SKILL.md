# Reels ideas and scripts

Work in the language of the user's videos. Ask once if you do not know it.

## Step 1. Benchmark 3 accounts

Ask for 3 accounts the user wants to learn from (same niche or the same audience). For each account, take the last ~60 videos. If you cannot open the platform, ask the user to paste titles, view counts and first sentences, or a screenshot of the grid.

For each account:
- **Reach.** Median views of the account. Mark every video with 10x the median or more: those are the outliers worth studying.
- **Hooks.** For each outlier: the first sentence, the first frame, the text on the cover. What stops the scroll: a question, a number, a contradiction, a strong image?
- **Topics and formats.** What comes back in the best videos. Format: list, ranking, myth vs fact, sketch, reaction, story.
- **Gap.** What nobody in this group does, but the audience clearly wants.

Output: a short table per account, then 3 to 5 patterns that repeat across accounts. Patterns, not copies: never reuse someone's script or footage.

## Step 2. Topic bank

Write 20 topics for the user, each one line: the topic, the format, and the hook in max 7 words. Mark which pattern from step 1 it uses. The user picks. Do not pick for them.

## Step 3. Script card

For the chosen topic write:

| Field | Rule |
|---|---|
| Hook | First sentence, max 7 words. No greeting, no brand name. |
| Frame 0 | What is visible in the very first frame. It should already mean something. |
| Text 0 to 3 s | On-screen text that works with the sound off. |
| Scenes | Table: time, speech, shot. A new stimulus every 3 to 5 s. |
| Punchline | The last sentence is a twist or payoff, never "follow me". |
| Description | Facts that did not fit in the speech, plus about 5 hashtags. |

Length: max ~25 s, about 60 words of speech. If it does not fit, cut facts into the description, not into faster speech.

## Step 4. Score before recording

Before the user records, score the script on three axes, each with three criteria from 0 to 10:
- **Stop:** hook tension, opening frame, "that's me" recognition.
- **Hold:** what the viewer waits for, rhythm, punchline.
- **Convert:** reason to save or send, brand recognition, credibility of claims.

Justify every score with a quote from the script. Score = average x average x average (max 1000). Calculate it with code, not in your head. Name the one change that gains the most points. Below ~500, fix the script before recording. Fixing text takes a minute, fixing it in the edit takes an hour.

The 3x3 method is by Jakub Biel: https://jakubbiel.pl/3x3/
